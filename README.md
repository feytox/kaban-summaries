# kaban-summaries

Конспекты курсов для Obsidian. У каждого курса своя папка `subjects/s<семестр>-<курс>/`: в файле курса собраны преподаватели, система оценки и акценты, в `notes/` лежат конспекты лекций и практик, в `tickets/` - карточки билетов.

Слайды и транскрипты занимают много места, поэтому папки `raw/` в репозитории нет и ссылки на них из конспектов не открываются. Ссылки на записи в Толке работают.

Конспекты пишет ИИ-агент по правилам из `AGENTS.md`. Для этого в `.agents/skills/` есть скиллы:

- `ingest-fast` и `ingest` делают конспект из материалов, положенных в `_inbox/`;
- `quiz` задаёт вопросы по материалу;
- `retell` проверяет пересказ лекции или билета.

Claude Code находит скиллы через symlink `.claude/skills`.

Свой прогресс агент записывает в `_private/`: уровни по темам, ошибки и пересказы. Папка в `.gitignore`, при желании её можно сделать отдельным git-репозиторием.
