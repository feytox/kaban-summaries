# kaban-summaries

Конспекты курсов в формате Obsidian: `subjects/s<семестр>-<курс>/`, внутри файл курса, `notes/` с конспектами лекций и практик и `tickets/` с билетами.

Исходники (слайды, транскрипты) лежат в `raw/` и в репозиторий не добавлены: много весят. Поэтому ссылки на них в конспектах не откроются, а ссылки на записи в Толке работают.

Конспекты пишет Claude Code по правилам из `AGENTS.md`. Скиллы в `.claude/skills/`:

- `ingest-fast`, `ingest` - конспект из материалов, положенных в `_inbox/`;
- `quiz` - опрос по материалу;
- `retell` - проверка пересказа лекции или билета.

Личный прогресс (уровни по темам, ошибки, пересказы) хранится в `_private/`, папка в `.gitignore`. Можно сделать её отдельным git-репозиторием.
