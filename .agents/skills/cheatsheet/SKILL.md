Read the notes in scope, their topics in mastery, the mistakes log (formats: `.agents/progress-formats.md`) and the test or exam format in the course file.

The sheet is read instead of the notes: state the material in it and link a note section only for details. It covers what I still need, weakest first:
- open mistakes: the correct version and the trap that caught me
- topics at level 0-1, then level 2
- level 3: one line each, for a quick self-check

When the course file describes the test format, shape the sheet to it, e.g. definitions in the length of the answer field.

Write as in the Form section of `.agents/skills/ingest-fast/note.md` and keep the content rules of AGENTS.md (по лектору, вне конспекта). Aim for about half the text of the notes covered.

Save it where I say as `<slug>-cheatsheet-<scope>.md` (scope like `L06-L07`), replacing an older sheet of the same scope there; ask if I didn't say where. Don't commit it: it is a snapshot that goes stale with the next quiz.
